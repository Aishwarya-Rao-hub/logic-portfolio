# Interactive Digital Logic & Number Systems Simulator

An interactive web application designed to simulate combinational logic gates and convert integer values into signed 8-bit binary, hexadecimal, and Two's Complement representations in real-time.

## Live Demo
[View Live App](https://chic-pony-7f1e65.netlify.app)

## Features
- **Combinational Logic Gate Tester**: Toggle binary inputs (A, B) to evaluate real-time outputs for AND, OR, NAND, NOR, XOR, and XNOR gates alongside their Boolean expressions.
- **8-Bit Number System Converter**: Convert signed decimal integers (-128 to 127) into standard 8-bit binary, hex, and two's complement representations.
- **Coursework Showcase**: Highlighting digital design breadboard labs, Verilog RTL modeling, and ASIC physical design progression.

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript (ES6)
- **Deployment**: GitHub, Netlify CI/CD
